Property	What it captures
Density	How many direct dependencies exist?
Degree heterogeneity	Are some variables hubs, or are degrees relatively uniform?

Depth Height	Are dependencies mostly direct, or do long causal chains occur?

Convergence and divergence	Do many causes combine into one variable? Does one cause affect many others?

Modularity	Are there relatively separate groups of interacting variables?

Feedback	Does the system contain cycles, or are cycles only absent in the chosen representation?
